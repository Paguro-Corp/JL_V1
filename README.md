# Jeffrey Levinson — Three Nights (Campaign Proposal v3)

An editorial social media campaign proposal for Jeffrey Levinson luxury evening clutches, created by Pagurai Creative.

## Overview

Three campaigns for Instagram and Facebook. Each campaign belongs to one clutch, one woman, and one night, featuring a hero static, a five-slide carousel, and two editorial alternates:

1. **Campaign 01: Vintage**
   - **Clutch:** Elina PLUS in Malbec lacquer with gold hardware (without chain).
   - **Protagonist:** The Collector, early 30s, ivory satin suit.
   - **Setting:** Private harvest dinner in a barrel-vaulted stone cellar and classic roadster.

2. **Campaign 02: Intermission**
   - **Clutch:** Elina PLUS in Mirrored Black Chrome with chrome hardware and wheat-braided chain (attached exclusively to the left side).
   - **Protagonist:** The Founder, mid 30s, royal cobalt-blue silk-velvet gown.
   - **Setting:** Modernist concert hall foyer during the intermission.

3. **Campaign 03: Between Places**
   - **Clutch:** Finley in Touring Red lacquer with chrome hardware (without chain).
   - **Protagonist:** The Maker, early 30s, camel wool coat and dark denim.
   - **Setting:** Wet urban street at night, from a gallery opening to a private dinner.

## How to View the Presentation

1. **Directly in Browser:**  
   Double-click `index.html` or drag it into any modern web browser (Chrome, Safari, Edge, Firefox).

2. **Local Web Server:**  
   ```bash
   # Using Node.js
   npx serve .
   
   # Or using Python
   python -m http.server 8000
   ```

3. **GitHub Pages (One-Click Deployment):**  
   In this repository, navigate to **Settings** > **Pages** > **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main` / Folder: `/ (root)`
   - Click **Save**.
